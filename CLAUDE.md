# Visionneuse STL

Nouvelle app (repartie de zéro) : on dépose des fichiers `.stl` dans la fenêtre, on les voit en 3D, on réduit leur nombre de triangles, on les retouche sommet par sommet, et on en tire des tranches à découper au laser.
Langue de travail : français (UI, commentaires), code en anglais. Commits : Conventional Commits en anglais.

## Stack
Vite + React 19 + TypeScript + Tailwind v4 + Three.js. Alias `@/` → `src/`. Pas de store : l'état vit dans `App.tsx`.

## Architecture
- `src/engine/viewer.ts` : `StlViewer`, Three.js pur (aucune dépendance React, pas de sol). `load()` lit un STL, le centre, le met à l'échelle (plus grand côté = 2), rendu flat-shaded. `sync(models, selectedId)` pousse l'état dans la scène. Pipeline du maillage affiché : original → `simplify(target)` (mis en cache) → retouche à la main (`overrides`, valable pour une cible donnée) ; `rebuild(id, target)`. Mode édition : `setEdit(id, target)`, `setEditTool`, `undoEdit` ; outils sommet / arête / triangle (survol = surbrillance rouge, clic = suppression), `select` (polygone en pointillés posé clic par clic, calque SVG par-dessus la vue ; double-clic / Entrée / clic sur le premier point ferme, Échap abandonne, Maj ajoute ; triangles dont un sommet ou le centre tombe dans le polygone, ou qui contiennent un sommet du polygone ; écartés si un tampon de profondeur logiciel (demi-résolution, rastérisation de tous les triangles, coût linéaire) montre quelque chose devant leur centre, sauf `setSelectThrough` ; surbrillance orange), `plane` (plan bleu transparent orientable dans toutes les directions : `setPlane({offset, angle, tilt, diag1, diag2, keep})`, `planeQuaternion()` = Rz(angle) · Ry(−tilt) · R(0,1,1)(diag1) · R(0,1,−1)(diag2) appliqué au carré de base (normale X, diagonales (0,1,±1)/√2 dessinées sur le carré), normale = X tourné, triangles teintés vert = gardés / rouge = supprimés selon leur centre ; `traceSection(on)` : trait rouge de l'intersection plan/modèle, segments enchaînés en contours, bouts ouverts (trous) pontés par une courbe de Hermite qui prolonge les tangentes (`bridge`), recalculé à chaque mouvement du plan ; `keepTrace()` : copie en rouge sombre attachée au mesh (visible hors édition), `removeTrace(id, i)`, `clearTraces(id, announce)`, `setTraces` / `exportTraces`, `generateTraces(axe X|Y|Z|D1|D2, pas°)` : un plan par pas autour de l'axe (X/Y/Z par le centre du modèle ; D1/D2 = diagonales du plan courant, par le centre du plan, premier trait = plan courant), chaque intersection gardée (`sectionLines(n, d)` factorise le calcul des contours) ; événement `onTraces(id, Float32Array[])` → `putTraces` dans IndexedDB (`<id>:traces`), rechargés au démarrage) ; `deleteSelection()` retire le cadre ou le côté rouge, `pendingDelete` en donne le nombre ; `mirrorAcrossPlane()` supprime le rouge puis `EditMesh.mirror()` : sommets du bord de coupe ramenés sur le plan (à moins de 1,5 × arête médiane), triangles couchés dans le plan retirés, copie miroir à orientation inversée partageant les sommets du plan ; événements `onEdit(id, triangles, positions)`, `onSelect(count)`, `onMessage`. `paintPieces` colore les triangles par pièce du patron (vertexColors). `exportStl` : maillage affiché en STL binaire.
- `src/engine/simplify.ts` : réduction par regroupement de sommets sur une grille (vertex clustering, déterministe, dichotomie sur la taille de cellule).
- `src/engine/meshEdit.ts` : `EditMesh` (sommets soudés + triangles indexés) : `removeVertex` (retriangule le trou par découpage d'oreilles, n → n − 2), `collapseEdge` (fusion au milieu, − 2 triangles), suppression directe d'un triangle = `tris.splice`.
- `src/engine/slices.ts` : tranches pour découpe laser. `sectionContours(pos, n, d)` (contours fermés de l'intersection plan/maillage, trous pontés par Hermite), `buildSlices(pos, planes, {mmPerUnit, thickness, wall})` : une tranche par plan (un plan par trait gardé, via `StlViewer.tracePlanes`), contours simplifiés (Douglas-Peucker 0,15 mm), creusés par décalage intérieur (`inset`, onglets limités, points trop près du bord retirés), rangées sur des planches A4 ; `sliceSvg` / `slicesHtml` (noir 0,1 mm = coupe, bleu = gravure, lien SVG par planche) ; `slicesGeometry` : aperçu 3D (ExtrudeGeometry par tranche, trous = `Shape.holes`, encoches non représentées). Mode « gaufre » (`makeWaffle` dans `App.tsx`) : deux familles de plans parallèles (directions X/Y/Z, un plan tous les N mm, `family` 0 / 1), `notch()` calcule à chaque croisement les encoches à mi-bois le long de la droite d'intersection des deux plans (intervalles de matière communs, A entaillée du côté t1 jusqu'au milieu, B du milieu au côté t2, largeur = épaisseur) ; les rectangles d'encoche dépassent du bord d'1 mm et sont coupés comme le reste. Les tranches « une par trait » n'ont pas d'encoches.
- `src/engine/meshEdit.ts` : soudure des sommets par table de hachage numérique (cellule de 10 µm, vérification exacte) : 292 000 triangles en ~1 s.
- `src/store/persist.ts` : **tout est enregistré automatiquement, par NOM de fichier** (plus de bouton Enregistrer) : redéposer un fichier de même nom le remet où on l'avait laissé. localStorage : liste de la session (`visionneuse-stl-modeles`) et réglages par nom (`visionneuse-stl-etats` : réduction, rotation, position, taille, couleur). IndexedDB (`visionneuse-stl` / `fichiers`) : octets du fichier par id de session, retouches `n:<nom>:edit` (cible + sommets) et traits `n:<nom>:traces`. `restoreWork(v, m)` (App.tsx) réapplique retouches, réduction et traits au chargement (session ou dépôt) ; migration automatique des anciennes clés par id. Retirer un modèle de la liste ne efface pas son travail ; « Tout rétablir » efface ses retouches.
- `src/App.tsx` : panneau (modèles ; maillage : triangles visés, préréglages, téléchargement ; édition à la main (sans limite de taille ; avertissement au-delà de 100 000 triangles, historique réduit à 15 étapes au-delà de 20 000) : outils sommet / arête / triangle / sélection polygonale (Maj : ajoute, case « faces cachées ») / plan de coupe vertical (position, orientation, côté gardé, symétrie), suppression par bouton ou touche Suppr, liste « Actions faites » avec un bouton Annuler par action (`undoTo(i)` : annule cette action et les suivantes ; `onHistory(labels)`), Ctrl+Z, tout rétablir ; préréglages de réduction 1 000 → 100 par pas de 100 ; tranches pour découpe laser (hauteur réelle, épaisseur du matériau, creuses + largeur de paroi, « Générer les tranches » = une par trait gardé, aperçu 3D remplaçant le maillage jusqu'à « Revenir au modèle », planches SVG) ; affichage : taille à l'écran, couleur) et dépôt de fichiers (glisser-déposer sur toute la fenêtre ou bouton). La réduction est recalculée 150 ms après le dernier changement de cible (`geoKey`). Restauration de la dernière session au démarrage.
- `src/ui/Slider.tsx` : curseur à valeur éditable au clavier (repris de l'archive), avec boutons − / + (un pas, Maj : dix pas).
- Section « Axes et plans » : par axe X / Y / Z, case « afficher » (axe général dans la vue, `setAxisVisible`) et case « activer » (plan ⟂ à l'axe, **fixe à l'origine des axes**, carré transparent + ligne de coupe rouge sur le modèle sélectionné, recalculée dans `sync()` via `updateWorldPlanes` quand le modèle bouge, tourne ou change de maillage : on déplace le modèle à travers le plan). Ces plans ne modifient rien ; ce sont des repères.

## Conventions de vue (comme dans l'archive)
- Repère : X = droite, Y = profondeur, Z = haut (`Object3D.DEFAULT_UP = (0,0,1)`).
- Caméra : clic gauche ou molette = tourner, clic droit = déplacer, roulette = zoom. Un clic sans glissé sur un modèle le sélectionne (hors mode édition).
- Les modèles sont rangés côte à côte à l'import (pas de déplacement), mais ils se **tournent** sur les trois axes (`ModelState.rot`, degrés XYZ, curseurs « Orientation et affichage »). La rotation reste une transformation du mesh (géométrie locale inchangée) : les outils d'édition, les traits et les tranches par trait travaillent en local ; la gaufre convertit les plans X/Y/Z de l'écran en local (`waffleLocalPlanes` : un plan sur l'axe lui-même, c'est-à-dire par l'origine de la scène, puis un tous les N mm vers chaque côté tant que le modèle est traversé ; la position du modèle compte, sa taille à l'écran non), la hauteur réelle utilise `rotatedSizeOf`, et `exportStl` applique la rotation. Position par curseurs X/Y/Z (jamais à la souris). Axes généraux dessinés dans la scène : X rouge, Y vert, Z bleu (hauteur), avec leur lettre en sprite.
- Matériau double face (`DoubleSide`) : après une suppression de triangles, l'intérieur se lit comme une surface, pas comme des arêtes flottantes.
- Vite sous Windows perd parfois un événement de modification quand deux éditions d'un même fichier sont très rapprochées : si le navigateur semble ignorer un changement, `touch` le fichier (ou relancer `npm run dev`).
- localStorage et IndexedDB sont partagés entre tous les onglets ouverts sur `localhost:5174` : deux onglets qui modifient la liste des modèles s'écrasent l'un l'autre.

## Limites connues
- Tranches creuses : le décalage intérieur est approximatif dans les pointes étroites (points trop près du bord retirés, pas de vrai calcul d'offset).
- Les tranches « une par trait » n'ont pas d'encoches ; seul le mode gaufre (deux familles parallèles) en calcule.
- La réduction par grille ne préserve pas les arêtes vives.
- Un fichier de plus de 10 Mo ne passe pas par le pont de test du navigateur de Claude ; dans Chrome il se charge normalement.
